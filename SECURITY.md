# Security Policy

## Supported Versions

Security fixes are applied to the latest maintained branch in this repository.

| Version | Supported |
| --- | --- |
| latest `main` | Yes |
| older snapshots | No |

## Reporting A Vulnerability

Please do not open a public issue for sensitive security reports.

Instead, report the problem privately through GitHub Security Advisories or contact the maintainer directly with:

- affected version
- reproduction steps
- impact assessment
- any suggested mitigation

You will receive an acknowledgement as soon as the report is reviewed.
